Project Requirements
* Goal: Create a fun and interactive way for users to hear a snicker while they begins to merge their code
* Non-Goal: Having other noises besides a snicker to play when the user merges
   * Non-functional requirement 1: Randomness in user studies
      * Functional requirements:
         * Run a program to select candidates at random and giving them keys
         * Keys will have limited access to the interface
   * Non-functional requirement 2: Ownership Capabilities 
      * Functional requirements:
         * Give users ownership over their own created repository
         * Control merge capabilities and be able to give ownership capabilities 
Agile
* Theme: Get GiggleGit demo into a stable enough alpha to start onboarding some adventurous clients
* Epic: Onboarding experience

* User Story 2: As a team lead onboarding an experienced GiggleGit user, I want to be able to track my team's commits through a clean and organized commit history
* User Story 3: As a beginner with no experience in version control user, I want to be able to access version control resources within GiggleGit
